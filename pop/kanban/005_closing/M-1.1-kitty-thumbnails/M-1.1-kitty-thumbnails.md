# M-1.1-kitty-thumbnails — real thumbnails via Kitty graphics protocol

- **Origin:** [[pop/MODIFICATIONS|M-1]]
- **Plan:** [[M-1.1-kitty-thumbnails.plan]] · **Approval:** [[M-1.1-kitty-thumbnails.approval]]

## What

Render search/playlist and "now playing" thumbnails as real images via the Kitty graphics protocol when the terminal supports it, with a `[ui] image_mode` config option (`auto|kitty|blocks`); the current pixelated `tview.Image` rendering remains as automatic fallback.

## Why

The user runs Kitty, which supports real images; the pixelated blocks waste that capability. Technical recon is already done (see Links), so planning starts from evidence.
