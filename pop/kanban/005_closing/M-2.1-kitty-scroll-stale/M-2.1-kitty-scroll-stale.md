# M-2.1-kitty-scroll-stale — fix stale Kitty placements on scroll up / item deletion

- **Origin:** [[pop/MODIFICATIONS|M-2]]

## What

Kitty thumbnails must track list content in every direction: scrolling up currently leaves placements static and mis-paired with text, and deleting a playlist item leaves the removed video's image on screen. Fix by content-keying sinks (videoID), always re-placing with fresh placement ids, forcing re-place on visible-window regeneration, and adding `YOUTUI_KITTY_DEBUG` sync logging.

## Why

The Kitty image mode shipped in M-1.1 misbehaves on upward scroll and deletion in real Kitty; the user hits it daily. Root cause is not decidable by reading (q=2 hides terminal errors), so the fix eliminates the whole bug class by construction.
