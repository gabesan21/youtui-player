# Thumbnail cache resolution raise

The cache downsize cap went from 100×100 to 640×640 px (`thumbnailMaxEdge`), JPEG q90 unchanged: 100 px was enough for pixelated blocks but too coarse for Kitty rendering, and 640 bounds disk use while Kitty scales to the placement cells itself. One cache path still serves both sinks — blocks reads the same files, so fallback rendering is unaffected. Added `GetThumbnailPath(WithContext)` returning the on-disk cache file the Kitty sink transmits from.
