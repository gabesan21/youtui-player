# `[ui] image_mode` config option

Added `ImageMode` to `UIConfig` (snake_case `image_mode`), defaulting to `"auto"` in `LoadConfig()`. `NormalizeImageMode()` lowercases/trims and maps any empty or unknown value to `"auto"`, so existing configs and typos keep the safe default; it is exported because the UI selects the thumbnail sink from the normalized value. The config DOX contract gained the normalization rule.
