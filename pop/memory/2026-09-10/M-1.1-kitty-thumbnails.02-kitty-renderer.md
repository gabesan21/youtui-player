# Kitty renderer primitive and placement lifecycle

New `kitty.go`: hand-rolled protocol subset (transmit file `a=T,t=f` from cache paths, place by cell `c/r` with `z=-1` below text, delete by placement id), no new dependencies. `Sync` reconciles per-frame placements; deletes on scroll/page (sinks drop out), resize and modal (`Invalidate`), and exit (`DeleteAll` after `Run()`). Emission is main-loop-only so escapes stay ordered before tcell's flush; blank `tview.Box` placeholders keep cell ownership.
