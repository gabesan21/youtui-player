# Render generation forces re-place, resolved once per prefix

`renderVisibleItems` bumps a per-list generation; `Sync` forces re-place of every sink of a bumped list, so scroll in any direction re-emits placements at current rects even when a spec compares equal. The 005 gate caught the first version consuming the bump on the first sink per prefix; the fixup (5fa8c00) resolves the flag once per prefix before the sink loops. The "player" key has no generation and never forces.
