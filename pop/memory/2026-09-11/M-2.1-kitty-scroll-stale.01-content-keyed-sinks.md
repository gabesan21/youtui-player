# Content-keyed Kitty sinks with fresh-id re-place

Kitty list sinks are keyed by content — `prefix:videoID` from the `i.ytimg.com/vi/<id>/` thumbnail URL, falling back to the track URL — never by index, so delete/move/page-change shifts cannot mis-pair a placement with another track. Any spec change deletes the old placement and re-places with a fresh placement id (fresh transmit only when the path changes). Accepted edge: duplicate same-video rows in one window collide on the key; one row degrades to blank.
