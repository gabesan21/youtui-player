# YOUTUI_KITTY_DEBUG per-Sync decision log

`YOUTUI_KITTY_DEBUG=<path>` makes each Kitty `Sync` append a timestamped record — desired vs live keys, deletes, places with rects and the per-key `force` flag — via one open/append/close per Sync. With the env var unset the buffer stays nil and there is literally no I/O: the terminal quirk behind the stale placements was not decidable by reading (`q=2` hides errors), so field diagnosis is part of the fix.
